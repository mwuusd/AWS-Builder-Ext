## ✨ 功能特性

### 🎯 核心功能

- **🤖 半自动注册** - 自动填写表单，验证码需手动输入
- **🔄 批量注册** - 支持自定义注册数量（1-100），一键批量创建账号
- **📧 Gmail 无限别名** - 利用 Gmail 特性生成无限邮箱变体
- **📧 支持域名邮箱** - 接入自己的域名邮箱服务
- **🕵️ 无痕模式** - 自动创建无痕窗口，隔离会话，防止数据污染
- **📊 账号导出** - 支持 JSON/CSV 格式

## 📦 安装指南

### 方式一：从源码安装（推荐）

1️⃣ **克隆仓库**
```bash
git clone https://github.com/mwuusd/AWS-Builder-Ext.git
cd AWS-Builder-Ext
```

2️⃣ **加载扩展**
- 打开 Chrome 浏览器
- 访问 `chrome://extensions/`
- 开启右上角「开发者模式」
- 点击「加载已解压的扩展程序」
- 选择项目根目录

3️⃣ **启用无痕模式**
- 在扩展卡片上，点击「详细信息」
- 找到「在无痕模式下启用」，**必须开启**
- 刷新扩展（点击刷新图标 🔄）

### 方式二：打包文件安装

1. 下载 [Code压缩包](https://github.com/mwuusd/AWS-Builder-Ext/archive/refs/heads/main.zip) 
2. 解压后按照「方式一」的步骤 2-3 加载

## 📖 使用说明

### 快速开始

1. **配置 Gmail 地址**：在插件弹窗中输入你的 Gmail 地址并保存
2. **或选择配置域名邮箱**：在插件弹窗中输入你的域名邮箱地址和API token并保存（第一次需要授权，授权同意再填一次保存）
3. **设置参数**：
   - 注册数量：1-100（建议 ≤ 10）
   - 并发窗口：建议设为 **1**（需要手动输入验证码）
4. **点击「开始注册」**
5. **GM需要手动填写验证码**：
   - 打开 Gmail 收件箱，找到 AWS 验证码邮件
   - 在注册页面手动输入验证码
6. **域名邮箱自动输入验证码**
7. **等待完成**，查看注册结果

### 功能详解

#### 📧 Gmail 配置

在插件弹窗顶部配置你的 Gmail 地址：

```
输入: example@gmail.com
保存后自动生成变体: example+240204abc@gmail.com, e.xample@gmail.com 等
```

#### ✅ 域名邮箱配置

在插件弹窗顶部配置你的域名邮箱地址和api token：

```
可以添加多个域名，注册时随机挑选一个生成随机邮箱地址
```

#### 📊 导出账号

- **导出**：导出本次注册任务所有的邮箱和密码，并标注结果
- **清空**：清空保存的注册信息


**支持的系统：**

| 系统 | 终端 | 配置文件路径 |
|------|------|-------------|
| Windows | PowerShell | `%USERPROFILE%\.aws\sso\cache\` |
| macOS | Terminal | `~/.aws/sso/cache/` |
| Linux | Terminal | `~/.aws/sso/cache/` |

## ⚠️ 注意事项

- ✅ **必须启用无痕模式权限**，否则无法创建无痕窗口
- ✅ **必须配置 Gmail 地址**，用于生成邮箱别名
- ⚠️ 验证码需要从 Gmail 收件箱手动获取并填写
- ⚠️ 建议并发窗口设为 1，方便手动输入验证码
- 📱 仅支持 Chrome 浏览器（基于 Manifest V3）
